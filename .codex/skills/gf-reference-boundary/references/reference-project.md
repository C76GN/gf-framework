# GF Reference Project Notes

The external reference project is currently expected at `../gf-reference-project` unless `GF_REFERENCE_PROJECT_PATH` is set.

## Source vs Generated Content

Reference project source can include its own `README`, `project.godot`, `src`, `scenes`, `resources`, `tests`, and local docs.

`addons/gf/` inside the reference project is generated by GF maintenance tooling. Treat it as synced output, not source to edit directly.

## Smoke Commands

```powershell
godot --headless --quit-after 10 --path ..\gf-reference-project --scene res://scenes/app/driftbound_boot.tscn
godot --headless --quit-after 10 --path ..\gf-reference-project --scene res://tests/smoke/driftbound_smoke.tscn
python tools\generate_api_coverage_matrix.py --examples ..\gf-reference-project --output ai_analysis\api_coverage_reference_project --check
```

Prefer `python tools\gf_maintenance.py check --suite examples --json`, which runs the configured scene paths and read-only sync check.
