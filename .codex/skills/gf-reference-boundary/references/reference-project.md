# GF Reference Project Notes

The reference project root is selected by explicit `--project-root`, then `GF_REFERENCE_PROJECT_PATH`, then the `../gf-reference-project` default. Boot and smoke scenes are selected by `GF_REFERENCE_BOOT_SCENE` / `GF_REFERENCE_SMOKE_SCENE` or `.gf_reference_project.json`; maintenance guidance must not assume a product-specific scene layout.

## Source vs Generated Content

Reference project source can include its own `README`, `project.godot`, `src`, `scenes`, `resources`, `tests`, and local docs.

`addons/gf/` inside the reference project is generated by GF maintenance tooling. Treat it as synced output, not source to edit directly.

## Canonical Checks

```powershell
python tools\sync_reference_project.py --check
python tools\gf_maintenance.py check --suite examples --json
```

The examples suite runs the configured scene paths, API coverage, and read-only sync check through one path-resolution contract. Use `python tools\sync_reference_project.py --plan` to preview a write and `python tools\sync_reference_project.py --apply` only for an explicitly authorized write sync. The default invocation and `--check` never write.
