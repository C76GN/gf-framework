# 第一个完整任务

在 GF 仓库的 Godot 项目中打开 `first_task.tscn`，按 F6 运行。选择“基础会话”或“异步服务会话”，加分、保存并退出，再次运行确认计数恢复。无需启用扩展，无需修改主场景或默认 Boot。

- `first_task.gd` 连接界面、按钮和窗口退出。
- `task_session.gd` 管理项目状态、设置服务装配与退出顺序。
- `task_service.gd` 展示异步演进：最多四份工作、显式取消、停止接纳与排空。

常规设置文件为 `user://gf_first_task.json`。首次缺失按显式策略采用默认值；损坏文件或不在 0 至 1,000,000,000 范围内的整数计数使启动失败，不覆盖旧数据。待处理增量也占用数值额度。保存失败保留计数，并阻止正常退出；可重试“保存并退出”。架构关闭失败会保留失败终态，重复退出不变成成功；错误时可显式选择强制退出，但不承诺持久化。

运行仓库验收：

```text
python tools/gf_maintenance.py check --suite examples --json
```

场景的 `--first-task-smoke` 使用独立临时文件，覆盖按钮到界面、同步保存、重启恢复、异步取消、退出排空、关闭期间拒绝新工作和保存失败重试；不会写入正常演示文件。

这是项目样例，不是框架模块；复制到自己的项目时保留完整 `addons/gf`，并修改样例中的 `res://examples/first_task/` 路径。设置键、文件名、业务状态、队列大小和退出策略属于项目。异步服务用帧推进模拟任务延迟，并不演示后台线程或不可强制终止的 IO。
