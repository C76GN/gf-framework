# 动画配方与整体节奏

高频的淡入、轻微强调和脉冲，可以从配置的 Steps 预设目录开始。每个配方显示用途、适用样机和运行前初值；应用后得到普通 `GFTweenActionStep`，可以逐步调整、保存和交给运行时动作。预设不创建另一套播放器，也不改变配置的循环、往返或恢复策略。

## 选择配方与检查初值

| 配方 | 适用目标 | 运行前提 | 步骤效果 |
| --- | --- | --- | --- |
| 淡入显示 | 2D、UI | `modulate.a` 为 `0`；颜色由项目决定 | alpha 从当前值到 `1` |
| 轻微强调 | 2D、UI、3D | `scale` 为单位向量 | 轻微收缩、放大，再回到单位缩放 |
| 缩放脉冲 | 2D、UI、3D | `scale` 为单位向量 | 放大到 `1.08`，再回到单位缩放 |

预设目录的初值是明确前提。工具可以在作者确认后把这些值用于隔离样机，帮助检查效果；它不会替项目设置真实节点的初态。只把预览样机变透明，不会让一个运行时已不透明的节点自动产生淡入。

运行时由项目建立基线。例如，对已经加载的淡入配置，项目可以在自己决定的显示时机设置 alpha，然后创建动作：

```gdscript
var config: GFTweenActionConfig = load("res://motions/reveal.tres")
panel.modulate.a = 0.0
var action: GFVisualAction = config.create_action(panel)
q_sys.enqueue(action)
```

这个例子只改变 alpha，保留真实节点的颜色。样机目录中的完整 `modulate` 默认初值是白色透明；需要检查有色节点时，明确调整样机颜色。真实节点的基线不是单位缩放时，应修改配方终点以匹配项目的静止缩放，不把 `Vector2.ONE` / `Vector3.ONE` 当成所有节点的正确姿态。

步骤的名称帮助区分同一属性的多个阶段。名称不改变播放时序，具体的按钮样式、成功提示或战斗事件仍由项目定义。

## 修改、恢复与复用

预设以版本 1 的纯数据记录保存步骤来源和受管字段基线。修改时长、目标值或缓动后，Steps 会显示覆盖字段。恢复一个字段或此步骤的全部受管字段会保留自定义 Curve；重新应用整套预设则沿用明确确认流程，替换全部步骤，包括曲线。

复制步骤同时复制有效 Curve，便于独立调整。预设不负责改变 Container 布局、节点 pivot 或共享材质，也不会保存预览用途到运行时配置。取消和完成后的属性恢复应使用配置已有的恢复选项；同属性接管可以复用显式的替换作用域，详见[配置化 Tween 动作](tween-config.md)。

震动优先使用已有的[反馈播放与采样](../feedback/shake-sampling.md)。反馈 channel 可以把合成偏移应用到 Camera、Control 或其他表现对象；不必为每个震动名称再建立动作服务。

## 用目标总时长调整节奏

准备一个有效、有限的配置后，可按希望的完整秒数换算 `duration_scale`。它包含延迟、串行组、并行组的最长分支、全部循环，以及往返的去程和回程；只修改已有倍率，保留每段之间的比例。

例如，两条并行分支各为 `0.5` 和 `1` 秒，随后串行 `0.5` 秒，一轮是 `1.5` 秒而非三段相加的 `2` 秒。两次完整往返共 `6` 秒；目标总时长设为 `3` 秒时，倍率从 `1` 变为 `0.5`。

零基准时长、无限循环、无效计划、过期来源、非有限或非正目标秒数不能换算。新倍率还须满足现有预览的保守时间预算：所有步骤的时长与延迟之和乘循环和往返次数不超过 `120` 秒。因此，即使并行后的实际总长较短，累计工作预算仍可能拒绝较大的目标值。目标总时长不是绕过预算的入口。

来源修改或撤销后，应基于新的有效准备结果再调整整体秒数；已经播放或定位的旧快照仍可以用于查看，却不能拿来计算另一份来源配置的倍率。调整倍率沿用原生 Undo / Redo，不重写每个步骤的时间值。
