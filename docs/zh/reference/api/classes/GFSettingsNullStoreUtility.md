# GFSettingsNullStoreUtility

[API Reference](../index.md) / [Standard](../standard.md) / [类索引](index.md)

- 路径：`addons/gf/standard/utilities/settings/gf_settings_null_store_utility.gd`

- 继承：`GFSettingsStoreUtility`
- API：`public`
- 类别：运行时服务 (`runtime_service`)
- 首次版本：`unreleased`

显式不可用的设置持久化 Store 哨兵。 该实现继承 GFSettingsStoreUtility 的明确 UNAVAILABLE 结果，适合测试隔离或显式 表达 Store capability 缺失。纯内存模式应在 GFSettingsUtility 上设置 persistence_enabled=false。
