# 3D 场景摆放

`gf.tool.scene_placement` 把用户选定的 `PackedScene` 放到当前编辑场景的指定 `Node3D` 下。它提供平面和碰撞表面拾取、网格、法线对齐与本地锚点；每次确认创建一个实例，并接入 Godot 原生 Undo / Redo。

工具复用已有场景文件，不建立资产库，也不定义关卡、物品或场景分类规则。

## 第一次使用

1. 启用 GF 编辑器插件，从 `工具 > GF > 打开 GF 工作区` 打开 [GF Workspace](../workspace.md)。
2. 选择“3D 摆放”页面，点击“打开 3D 摆放工具”。Godot 主编辑器右侧会出现独立摆放侧栏，便于同时操作 3D 视口。
3. 点击“选择场景”，选择根节点为 `Node3D` 或其派生类型的 `.tscn` / `.scn`。工具不会把当前正在编辑的场景放回其自身。
4. 在当前场景树里选择一个父 `Node3D`，再点击“使用当前所选 Node3D”。之后普通的选择变化不会偷偷替换这个父节点。
5. 设置参数，点击“开始摆放”，在 3D 视口中移动指针查看线框代理。左键或 Enter 确认一次摆放；Esc、右键或“取消预览”取消。
6. 确认后使用 Godot 编辑器的 Undo / Redo 撤销或重做，按正常场景保存流程保存结果。继续摆放需要再次点击“开始摆放”。

“关闭摆放工具”会关闭独立侧栏并停用原生子插件。启用和关闭是用户主动的插件设置操作。关闭 GF 工作区窗口只隐藏窗口；页面被重建、工作区被释放或 GF 插件被停用时，启动页会在当前生命周期回调结束后关闭它所管理的摆放子插件。新页面可延续对同一插件实例的管理，并作废旧关闭请求。

启动页只管理由“打开 3D 摆放工具”从停用状态启用的实例。若用户已在 Godot 的插件设置中独立启用工具，页面构建、重建、卸载，以及再次点击“打开”都不会取得关闭权。用户独立停用后重新启用的实例也不再由旧页面管理；显式点击“关闭摆放工具”仍可关闭它。卸载 GF 文件前，先关闭摆放工具和 GF 插件。

## 拾取与变换

| 参数 | 语义 |
| --- | --- |
| 平面 | 使用世界空间的平面原点和法线求射线交点。默认是经过世界原点的水平面；法线朝向入射射线。平行、背后或超出最大距离的命中无效。 |
| 碰撞表面 | 查询当前 3D 编辑器视口 World3D 中、命中掩码内的物理碰撞体。单有可见 Mesh 没有碰撞体时不会命中，Area 不参与查询。 |
| 切向网格 | `0` 关闭；正数按命中法线的切向网格吸附，网格原点使用“平面 / 网格原点”。保留到该平面的法线距离。表面模式使用命中点的切平面，吸附后不会再次投射到曲面或检测边缘。 |
| 法线对齐 | 将源场景根的局部 Y 轴旋转到命中法线。 |
| 偏航 | 绕世界 Y 轴旋转；启用法线对齐后改为绕命中法线旋转。 |
| 局部缩放倍数 | 乘到源场景根已保存的 basis 上。不能为零，允许明确的镜像缩放。 |
| 源根本地锚点 | 源场景根坐标系中的一个点。默认 `(0, 0, 0)`；工具调整实例原点，使该点落到最终命中位置。不自动解析 Marker3D 名称或项目锚点约定。 |
| 沿法线偏移 | 在吸附后沿命中法线平移锚点，可为负数。 |
| 线框代理尺寸 | 用户声明的本地包围盒尺寸，以源根原点为中心；它不是实际模型边界或缩略图。 |
| 最大拾取距离 | 正数，最大 `100000`；超出范围没有有效预览。 |

默认保留源场景根已保存的旋转和缩放，源根的位置由本次命中和锚点替代。启用法线对齐、偏航或额外缩放时，这些参数继续作用于该 basis。预览与确认使用同一世界变换；确认时重新根据父节点当前的世界变换换算局部变换，因此旋转、平移或非均匀缩放的父节点不会把世界命中点误当局部位置。源根使用 `top_level` 时按其原生世界变换语义摆放。

入树和 owner 设置期间的同步回调结束后，工具最终施加确认的世界变换；如果此时原场景、父节点、owner 或最终变换不再满足条件，确认失败并移除本次实例。之后工具脚本在后续帧持续调整变换的行为仍由项目控制。

数值必须有限，向量和普通数值的绝对值上限为 `1000000`；缩放分量的绝对值不得小于 `0.000001`，父变换必须可逆。零法线、无效参数、失效父节点和无有效命中都不能确认。

## 预览、取消与历史

预览只计算变换并绘制工具自己创建的线框，不向编辑场景添加节点，不实例化源场景，也不复制或修改来源资源。源场景的选择和加载仍使用 Godot 的资源系统；代理不声称显示脚本生成的几何、实际 Mesh 或实时物理形状。

修改参数、重新选择来源或父节点、切换场景、隐藏侧栏、关闭工具都会取消待确认的预览。一次无效命中也会清除上一次的可确认位置，避免落到旧位置。

确认按普通编辑器实例化流程运行场景的工具脚本。撤销移除本次创建的实例，重做复用同一个存活实例；关闭侧栏不会让历史失效。父节点已经移到其他场景时，原场景的撤销会拒绝修改它。撤销后丢弃该历史时，仍脱树的实例会被释放。历史只管理该实例的场景结构和放置变换，不撤回工具脚本对其他对象或文件产生的动作。

## 自定义编辑器入口

`GFScenePlacementOperation` 是可复用的制作期入口，继承 `GFEditorPickOperation`。它把视口输入转换为纯变换预览，并把一次确认转换为原生编辑命令，适合自定义 `EditorPlugin` 复用同一流程。

1. 用 `configure(scene, parent, scene_root, options)` 配置来源、目标和参数。未知选项或错误类型会被拒绝；活动操作或正在提交时再次配置返回 `ERR_BUSY`。
2. 用包含当前场景根和撤销管理器的 `GFEditorToolContext` 调用 `begin(context)`。
3. 平面模式向 `pick()` 传入 `ray_origin` / `ray_direction`；表面模式传入 `hit: { position: Vector3, normal: Vector3 }`。表面射线查询由调用方负责，操作本身不扫描场景。
4. 通过 `get_preview()` 读取 `valid`、`world_transform`、`local_transform`、`position`、`normal` 和 `reason`。`local_transform` 是按当前父变换计算的父坐标换算值；`top_level` 根的原生 `transform` 使用 `world_transform`。仅在 `can_apply()` 为真时确认。
5. `apply()` 至少返回 `ok` 和 `reason`；实际提交结果另有 `error_code` 和创建的 `node`。必须检查实际结果；缺少撤销管理器时拒绝实例化。取消则调用 `cancel()`。

确认及失败补偿期间，来自同步回调的再次 `apply()` 返回 `ERR_BUSY`，`begin()` 返回 `false`，`pick()` 保留当前状态。显式取消仍有效，但不能在同一提交回调中重新配置或启动这个操作。

这个入口只接受当前编辑场景内仍存活的目标，不把选择状态变成全局服务。项目的资产选择、批量排布、随机化、命名和跨工具流程继续由项目决定。
