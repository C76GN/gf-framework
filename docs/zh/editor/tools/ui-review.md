# 真实页面对照

在 GF 工作区打开 **开始制作 → 真实页面对照**。该工具由独立编辑器工具包 `gf.tool.ui_review` 提供，可以在静态页面或带动效的页面上使用。

选择项目自己的 PackedScene、状态标识和采样时刻。填写窗口尺寸、语言、UI 缩放列表，运行后可并排看图。选择 **实播所选场景** 会使用第一组配置打开独立游戏窗口，可验证只支持向前模拟的项目动作。关闭窗口或停止采样即可返回。每个组合由独立游戏进程运行，并使用自己的临时用户目录。结果目录内的 PNG 以及 JSON 记录实际窗口、语言、控件路径、矩形和文本。若项目采用自定义缩放或延迟布局，使用可选场景钩子对齐正式流程。

`Label` 的布局记录同时保存 `source_text`（原始文本）和 `text`（遵循控件自动翻译设置的文本）。换行、裁切和最终字形可以在同一组 PNG 中核对。实播在场景准备完成前退出时，工作区会显示失败原因和日志目录。

| 可选方法 | 调用时机 |
|---|---|
| `configure_ui_review(options)` | 根节点入树前，注入同一状态、语言、缩放、种子和样例数据 |
| `prepare_ui_review(options)` | 节点就绪后，可等待布局、应用项目自己的界面倍率 |
| `sample_ui_review(seconds)` | 采图前按同一时刻定位表现。未提供时等待指定时长 |

默认窗口组合包括 1280×720、960×540、1470×630 和 540×810。状态、种子和采样秒数在各组合中保持一致。界面提示可打开的结果路径，提前停止会保留已经完成的图片与诊断。

采样进程会从磁盘重新打开场景。编辑中的页面或配方需要先保存，页面引用的资源才会随这次采样加载。
