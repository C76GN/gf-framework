# 更新日志 (Changelog)

## [12.0.1] - 2026-11-19

**版本概述**：本维护版本修复了 Windows 发布流水线的发行包校验，恢复通过正式标签自动构建、校验和发布安装包的流程。已有 GF 12.0.0 项目可直接升级。

### 🐛 Bug 修复 (Fixed)

- Windows 发布任务在项目的临时产物目录中创建发行包校验快照，避免运行器临时路径触发快照边界错误。发布仍逐一校验四个归档的 SHA-256。

### 📘 升级指南 (Migration Guide)

- 已使用通用包的项目可直接更新整个 `addons/gf/`。Windows x64 项目可改用同版本完整包，或将通用包与同版本原生补充包配套安装。
- 从 GF 11 或更早版本升级时，请先查阅 [12.0.0 的迁移说明](https://github.com/C76GN/gf-framework/blob/12.0.0/docs/zh/changelog.md#1200---2026-11-18)。
