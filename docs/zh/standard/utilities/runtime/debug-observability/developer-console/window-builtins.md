# 控制台窗口与内置命令

按下 **F1**（可配置）即可呼出半透明控制台。默认保持全屏覆盖；也可以启用窗口模式，让控制台以可拖拽、可缩放面板呈现。

控制台内置命令如下。方括号表示可省略的参数，等号后是默认值；输入命令时不需要输入方括号。

| 用法 | 行为 |
| --- | --- |
| `help` | 列出所有指令、描述及内置命令的用法；不接受参数。 |
| `clear` | 清空输出；不接受参数。 |
| `scene.tree [max_depth=3] [max_nodes=80] [root_path=.]` | 输出只读场景树摘要。参数依次为最大深度、最大节点数、根节点路径。 |
| `scene.node [path=.]` | 输出指定节点的只读摘要。 |

`max_depth` 必须是非负十进制整数，`max_nodes` 必须是正十进制整数，均不超过 `9223372036854775807`。支持正号和前导零；`-0` 按零处理。小数、空数字和溢出值会被拒绝。深度从根节点的 `0` 开始计数，节点数包含根节点；它们是本次遍历的上限，数值合法不代表大范围同步遍历没有成本，调试时应按需要设置较小值。

省略路径、`.` 和空字符串 `""` 都选择当前场景；当前场景不存在时使用 SceneTree 根节点。相对路径优先从当前场景查找，再从 SceneTree 根节点查找；绝对路径从 SceneTree 根节点查找。路径带空格时可以使用引号或反斜杠转义：

```text
scene.tree 2 20 "World Root"
scene.node "World Root/Player"
```

内置命令遇到多余参数、非法数字或找不到的路径时，会在控制台显示具体原因和用法，并停止该操作。例如 `scene.tree nope` 不再静默使用默认深度，`clear extra` 也不会清空已有输出。反馈中的参数和路径作为普通文本显示，不解释为 BBCode。

`execute_command()` 的返回值表示输入是否已派发给命令回调，不表示回调业务成功；内置命令报告参数错误后仍返回 `true`。项目命令继续接收原始的 `PackedStringArray`，自行校验参数，回调返回值不参与派发结果。

控制台会自动接收 `GFLogUtility` 的日志信号并着色显示：Error/Fatal 红色、Warn 黄色、Debug 青色。

界面内置日志标签过滤输入框，支持 `Tab` 补全命令、上下方向键切换输入历史。未知命令也可通过 `suggest_similar_commands()` 给出相似候选。

命令需要参数补全时，可以在注册 metadata 中传入 `argument_suggester`，或在 `GFConsoleCommandDefinition.argument_suggester` 上挂运行时 Callable。回调接收 `command_name`、`args`、`argument_index`、`prefix` 和 `raw_input`，返回“参数语义值”字符串数组；控制台按当前参数前缀过滤，并用与命令 parser 对称的引号/反斜杠编码写回。空字符串、首尾空白、空格、单双引号和反斜杠都能作为一个 token 往返，suggester 不应预先加入展示用引号。

`argument_suggester` 当前是主线程同步、受信任的调试回调；普通快照不会调用它，但一次 Tab 会执行一次。应只返回已经缓存的小型候选集，不要在回调中同步扫描资源树、访问网络或构造无界数组。统一的候选数量、字符串长度与执行时限合同尚未建立，因此项目仍需主动保持该回调有界。
