## 项目所有的存储 Provider 边界，由 ProjectStorageBackend 调用；真实接入应替换为范围明确的 SDK 包装。
## 默认方法刻意不可用，空骨架不能通过一致性验收；读取和列举必须在下载、解码或分配结果前执行传入硬预算。
## [br]
## @api framework_internal
class_name ProjectStorageProvider
extends RefCounted

	return {
		"ok": false,
		"data": {},
		"metadata": {},
		"error_code": int(ERR_UNAVAILABLE),

## 由真实 Provider 原子提交数据、metadata 和修订；失败必须保留原记录，当前骨架拒绝写入。
## [br]
## @api framework_internal
## [br]
## @param _storage_key: 已验证的完整存储键。
## [br]
## @param _data: 已通过有界纯值校验并深复制的业务数据。
## [br]
## @schema _data: Dictionary，String 键，值递归限制为 null、bool、int、有限 float、String、Array 和同类 Dictionary。
## [br]
## @param _metadata: 不含 write_options 或调用方 revision 的元数据副本。
## [br]
## @schema _metadata: Dictionary，遵守同一纯值预算；新 revision 由 Provider 提交时生成。
## [br]
## @param _write_options: 已校验的条件写选项。
## [br]
## @schema _write_options: Dictionary，可选 expected_revision:String、create_if_absent:bool、request_id:String；revision/request_id 是有界非空不透明 token，create_if_absent=true 与 expected_revision 互斥。
## [br]
## @return 成功为 OK，条件冲突或提交失败为稳定 Godot Error；当前为 ERR_UNAVAILABLE。
func write_record_atomic(

	return ERR_UNAVAILABLE

func list_records(
	_storage_prefix: String,
	_list_limits: Dictionary
) -> Dictionary:
	return {
		"ok": false,
		"records": [],
		"error_code": int(ERR_UNAVAILABLE),
	}
